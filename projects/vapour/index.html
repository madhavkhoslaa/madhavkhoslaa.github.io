Vapour CLI and Profiler

October 14, 2026 · 1 min
Date
October 14, 2026
Canonical URL
https://madhavkhoslaa.github.io/projects/vapour/

Tooling for Vapour (External link), a platform for web games.

  • vapour-cli (External link) (Go, MIT). Logs in, creates a game project, and builds and publishes web exports for Godot, Unity and Bevy. It scans and signs build zips, does chunked and delta uploads, and runs games locally with an FPS overlay (vapour test).
  • vapour-profiler (External link) (Rust, eBPF). A standalone, local-first eBPF profiler for Wasm runtimes and Linux processes. It uses CO-RE BPF attach/detach, and capture is explicit and bounded. It ships a local performance dashboard and per-asset load observability.
