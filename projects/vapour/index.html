Vapour CLI and Profiler

Madhav Khosla
Oct 14, 2026

Tooling for Vapour, a platform for web games.

  • vapour-cli (Go, MIT). Logs in, creates a game project, and builds and publishes web exports for Godot, Unity and Bevy. It scans and signs build zips, does chunked and delta uploads, and runs games locally with an FPS overlay (vapour test).
  • vapour-profiler (Rust, eBPF). A standalone, local-first eBPF profiler for Wasm runtimes and Linux processes. It uses CO-RE BPF attach/detach, and capture is explicit and bounded. It ships a local performance dashboard and per-asset load observability.
