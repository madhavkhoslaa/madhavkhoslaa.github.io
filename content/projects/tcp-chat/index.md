A multi-client TCP chat server in Rust. It handles concurrent connections, broadcasts messages, and keeps per-client state, with colored terminal output. Connect with `nc 127.0.0.1 5000`.

Source: [github.com/madhavkhoslaa/chat-server](https://github.com/madhavkhoslaa/chat-server)
