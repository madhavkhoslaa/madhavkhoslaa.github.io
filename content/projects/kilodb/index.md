A Redis-compatible key-value server on Rust TCP sockets. It parses the RESP wire protocol and serves concurrent clients. It supports Strings, Hashes, Lists, Sets, TTL and key management commands.

Source: [github.com/madhavkhoslaa/KiloDB](https://github.com/madhavkhoslaa/KiloDB)
